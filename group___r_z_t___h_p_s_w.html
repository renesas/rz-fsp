Detailed Description

Provides API for using Ethernet Switch. This module implements the Ethernet Switch Interface.

Overview

With the HSR/PRP Switch function, this LSI enables to build the network topology such as line type without external switching hub.

Features

  • If start this module, it has behevia following as two mode.
    • 1) Redbox mode
    • 2) Dun mode
  • The mode is decided by connecting network. etc..

Usage Notes

Then use this modules, set to start the Adjustable Clock on the application.

Limitations

Developers should be aware of the following limitations when using the HPSW:

  • Non-averable the pulse generater.
  • The HPSW module does not support timers other than the HPSW timer (ETHSW or ESWM timers). While the input timer clock can be configured in the "Timer Signal and Clock Selection Register," selecting a timer other than the HPSW timer will prevent the HPSW from functioning correctly in slave mode according to the product specifications.

Examples

Basic Example

This is a basic example of minimal use of the HPSW in an application.

void hpsw_basic_example (void)
{
fsp_err_t err = FSP_SUCCESS;
hpsw_cfg_t hpsw_cfg = {0};
hpsw_counter_t hpsw_counter = {0};
hpsw_ptp_dataset_t hpsw_ptp_dataset = {0};
hpsw_status_t hpsw_status = {0};
// Configure Adjustable Clock
hpsw_cfg.clk_select = HPSW_CLOCK_PTP;
hpsw_cfg.time_val = 0x1;
// Configure PTP TC
hpsw_cfg.ptp_tc_profile = HPSW_PTP_TC_DEFAULT;
hpsw_cfg.ptp_tc_profile_val = 0x1;
hpsw_cfg.ptp_tc_default_data_1 = HPSW_EXAMPLE_TC_DEFAULT_DATA_1;
hpsw_cfg.ptp_tc_default_data_2 = HPSW_EXAMPLE_TC_DEFAULT_DATA_2;
hpsw_cfg.ptp_tc_clock_id_val = 0x1;
// Configure PTP OC
hpsw_cfg.ptp_oc_profile = HPSW_PTP_OC_DEFAULT;
hpsw_cfg.ptp_oc_dis_offset_correction = 0x1;
hpsw_cfg.ptp_oc_profile_val = 0x1;
hpsw_cfg.ptp_oc_default_data_1 = HPSW_EXAMPLE_OC_DEFAULT_DATA_1;
hpsw_cfg.ptp_oc_default_data_2 = HPSW_EXAMPLE_OC_DEFAULT_DATA_2;
hpsw_cfg.ptp_oc_clock_id_val = 0x1;
// Configure HSR/PRP
hpsw_cfg.mac1 = HPSW_EXAMPLE_MAC_1;
hpsw_cfg.mac2 = HPSW_EXAMPLE_MAC_2;
/* Open the hpsw instance with initial configuration. */
err = R_HPSW_Open(&g_hpsw0_ctrl, &g_hpsw0_cfg);
/* Handle any errors. This function should be defined by the user. */
assert(FSP_SUCCESS == err);
/* Enable HSR/PRP switch. */
err = R_HPSW_EnableSet(&g_hpsw0_ctrl, &hpsw_cfg, HPSW_EXAMPLE_ENABLE);
assert(FSP_SUCCESS == err);
/* Enable the transmission and reception of Ethernet frames. */
err = R_GMAC_B_Open(&g_ether0_ctrl, &g_ether0_cfg);
assert(FSP_SUCCESS == err);
/* Get port counter values. */
err = R_HPSW_CounterGet(&g_hpsw0_ctrl, HPSW_EXAMPLE_PORT, &hpsw_counter);
assert(FSP_SUCCESS == err);
/* Clear counter values. */
err = R_HPSW_CounterClear(&g_hpsw0_ctrl);
assert(FSP_SUCCESS == err);
/* Get current dataset. */
err = R_HPSW_PtpDataGet(&g_hpsw0_ctrl, &hpsw_ptp_dataset);
assert(FSP_SUCCESS == err);
/* Get port status. */
err = R_HPSW_StatusGet(&g_hpsw0_ctrl, &hpsw_status);
assert(FSP_SUCCESS == err);
/* Disable HSR/PRP switch. */
err = R_HPSW_EnableSet(&g_hpsw0_ctrl, &hpsw_cfg, HPSW_EXAMPLE_DISABLE);
assert(FSP_SUCCESS == err);
/* Close the hpsw instance. */
err = R_HPSW_Close(&g_hpsw0_ctrl);
assert(FSP_SUCCESS == err);
}
