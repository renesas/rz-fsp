Arm Mailbox (rm_arm_mailbox_mhu)
RZG » Modules » AI

Middleware that implements the Ethos-U core driver's Mailbox interface on top of the RZ MHU driver.

Overview

RM_ARM_MAILBOX_MHU is a C++ implementation of the Mailbox::Mailbox interface used by the Arm Ethos-U core driver and core-platform to exchange messages with a peer core. It bridges that interface to the Message Handling Unit in NonSecure (r_mhu_b_ns) driver, so an Ethos-U NPU application can use the standard Arm mailbox API without depending on RZ-specific MHU details.

This module is not intended for direct use from application programs; it is used in combination with Ethos-U NPU (rm_ethosu).

This module requires an Message Handling Unit in NonSecure (r_mhu_b_ns) driver stack to be added underneath it in the stack configurator.

Features

  • Opens and closes the underlying Message Handling Unit in NonSecure (r_mhu_b_ns) channel
  • Sends a message to the peer core
  • Dispatches received messages to registered Mailbox::registerCallback() callbacks

Configuration

Note
rm_arm_mailbox_mhu acts as a bridge between the Renesas MHU and the ARM Mailbox, no Configuration settings are required. If the user needs to configure anything, that should be done on the MHU module side.

Usage Notes

The default constructor, RM_MHU(), uses the MHU instance generated by the stack configurator. The constructor that takes an mhu_instance_t allows an explicit instance to be supplied instead, which is useful for tests or applications managing multiple mailbox channels.

Construction opens the underlying MHU_B_NS channel and registers RM_MHU's internal callback with it. If the driver's open() or callbackSet() calls fail, the error is treated as unrecoverable (BSP_CFG_HANDLE_UNRECOVERABLE_ERROR), so the MHU_B_NS driver instance must be fully and correctly configured before an RM_MHU object is constructed.

Examples

Basic Example

This is a basic example of minimal use of the Arm Mailbox implementation in an application.

/* Application callback invoked from RM_MHU::handleMessage() whenever the peer core sends a message. */
static void rm_arm_mailbox_mhu_message_received (void * p_context)
{
FSP_PARAMETER_NOT_USED(p_context);
}
void rm_arm_mailbox_mhu_basic_example (void)
{
/* Opens the MHU_B_NS channel and registers RM_MHU's internal callback with it. */
RM_MHU mailbox(g_mhu_b_ns0);
/* Register an application callback to run when a message is received. */
mailbox.registerCallback(rm_arm_mailbox_mhu_message_received, nullptr);
/* Notify the peer core that a message is available. */
mailbox.sendMessage();
}
