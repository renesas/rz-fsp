Detailed Description

Driver for the DOC peripheral on RZ microprocessor. This module implements the DOC Interface.

Overview

Features

The DOC HAL module peripheral is used to compare, add or subtract 16-bit data and can detect the following events:

  • A match or mismatch between data values
  • Overflow of an addition operation
  • Underflow of a subtraction operation

A user-defined callback can be created to inform the CPU when any of above events occur.

Clock Configuration

The DOC HAL module does not require a specific clock configuration.

Pin Configuration

The DOC HAL module does not require and specific pin configurations.

Usage Notes

Interrupt

The DOC outputs an error signal to the ICU. ICU can output PERI_ERRn interrupt (Peripherals error event n) to GIC or cause error reset when ICU accepts error signal from DOC. To use PERI_ERRn interrupt or reset at DOC, ICU ERROR (r_icu_error) need to be configured. When the PERI_ERRn interrupt is configured to use interrupt and triggered, the callback function registered during open is called.

DMAC Integration

DOC can be used with Transfer (r_dmac) to write to the input register without CPU intervention. DMAC is more useful for most DOC applications because it can be started directly from software. To write DOC input data with DMAC, set transfer_info_t::p_dest to R_DOC->DODIR.

Examples

Basic Example

This is a basic example of minimal use of the R_DOC in an application. This example shows how this driver can be used for continuous 16 bit addition operation while reading the result at every overflow event.

Note
When using this example code, Set module configuration value as below.
  • r_doc
    • Callback is "doc_callback".
  • r_icu_error
    • Interrupts > PERI_ERR0 > Interrupt Priority is arbitrary priority.
    • Interrupts > Callback is "error_callback".
    • Error Events > Peripherals > PERI_ERR0 interrupt enable > Peripheral Error 0 > DOC_DOPCI (ERREVENT18) is enabled.
      • The DOC_DOPCI signal can also be assigned to PERI_ERR1. In that case, set "Interrupts > PERI_ERR1 > Interrupt Priority" and "Error Events > Peripherals > PERI_ERR1 interrupt enable > Peripheral Error 0 > DOC_DOPCI (ERREVENT18)".
    • Peripheral Error Handler > Peripheral Error 0 > ERREVENT18 is set to "doc_int_isr" by default, which is implemented in the DOC HAL driver.
    • This is an example on RZ/T2H. The assignment of the actual DOC_DOPCI signal to a specific ERREVENT is dependent on the product implementation.
#define DOC_EXAMPLE_VALUE 0xF000
uint32_t g_callback_event_counter = 0;
/* This callback is called when DOC overflow event occurs. It is registered in doc_cfg_t when R_DOC_Open is
* called. */
void doc_callback (doc_callback_args_t * p_args)
{
FSP_PARAMETER_NOT_USED(p_args);
g_callback_event_counter++;
}
/* This callback is also called when a DOC overflow event occurs. It is registered in error_cfg_t
* when R_ICU_ERROR_Open is called. */
void error_callback (error_callback_args_t * p_args)
{
#if ((3 == BSP_FEATURE_ICU_ERROR_PERIPHERAL_TYPE) || (4 == BSP_FEATURE_ICU_ERROR_PERIPHERAL_TYPE))
if ((ERROR_EVENT_PERIPHERAL_0 == p_args->error_event) &&
(ICU_ERROR_PERIPHERAL_ERROR_0_DOC_DOPCI == p_args->error_status))
{
R_ICU_ERROR_StatusClear(&g_error0_ctrl, ERROR_EVENT_PERIPHERAL_0, ICU_ERROR_PERIPHERAL_ERROR_0_DOC_DOPCI);
}
#else
if ((ERROR_EVENT_PERIPHERAL_1 == p_args->error_event) &&
(ICU_ERROR_PERIPHERAL_ERROR_1_DOC_DOPCI == p_args->error_status))
{
R_ICU_ERROR_StatusClear(&g_error0_ctrl, ERROR_EVENT_PERIPHERAL_1, ICU_ERROR_PERIPHERAL_ERROR_1_DOC_DOPCI);
}
#endif
}
void basic_example (void)
{
fsp_err_t err;
/* Open the ICU_ERROR driver to configure behavior when the DOC event occurs. */
err = R_ICU_ERROR_Open(&g_error0_ctrl, &g_error0_cfg);
/* Handle any errors. This function should be defined by the user. */
assert(FSP_SUCCESS == err);
/* Initialize the DOC module for addition with initial value specified in doc_cfg_t::doc_data. */
err = R_DOC_Open(&g_doc0_ctrl, &g_doc0_cfg);
assert(FSP_SUCCESS == err);
/* Write data to the DOC Data Input Register and read the result of addition from status register when an
* interrupt occurs. */
for (int i = 0; i < 5; i++)
{
err = R_DOC_Write(&g_doc0_ctrl, DOC_EXAMPLE_VALUE);
assert(FSP_SUCCESS == err);
/* When the CPU operation is fast, there is a time lag with the operation of the DOC module. */
R_BSP_SoftwareDelay(1U, BSP_DELAY_UNITS_MICROSECONDS);
if (g_callback_event_counter >= 1)
{
uint32_t result;
/* Read the result of the operation */
err = R_DOC_Read(&g_doc0_ctrl, &result);
assert(FSP_SUCCESS == err);
}
}
}
